# Reproduction

Requirements: Python 3.9+ standard library for calculations and tests. Matplotlib is optional and needed only to rebuild the two figures.

From this directory run:

1. `python3 src/completion.py`
2. `python3 src/denominators.py`
3. `python3 src/summarize.py`
4. `python3 src/unknown_overlay.py`
5. `python3 src/verify.py`
6. `python3 -m unittest discover -s tests -v`
7. `python3 src/figures.py` (optional)

The public verifier reconstructs all 4,510 finite limiting-radius witness vectors and 2,932 checkpoint vectors, checks their full factor vectors and all product outcomes, and checks the 80 no-finite-witness records without inventing finite vectors; it also verifies exact product universes, unique case identities, disjoint status partitions, and H3 event-pair reaggregation. Calculations use rational arithmetic from decimal input strings; center quantization is separately reconstructed with ROUND_HALF_EVEN. No random sampling or probability interpretation is used. Copied-input hashes and source provenance are listed in `INPUT_MANIFEST.json`.


The active witness outputs are `results/checkpoint_witnesses.csv`, `results/checkpoint_witness_outcomes.csv`, `results/limiting_witnesses.csv`, and `results/limiting_outcomes.csv`. The older `witnesses.csv`, `witness_outcomes.csv`, and `checkpoint_*_k3.csv` exports are preserved under `history/proposal1/legacy_witnesses/`. They belong to the earlier proposal's witness/checkpoint grid, are not generated by these commands, and are not inputs to current summaries or verification. Reproducing those archived exports requires the earlier proposal's code and run instructions; they are retained only for provenance and are not evidence for the current candidate's active results.
